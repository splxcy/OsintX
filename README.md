# OSINTX 🔍

**OSINTX** es una plataforma de inteligencia de fuentes abiertas (OSINT) que centraliza en una sola interfaz web el análisis de datos públicos sobre emails, usernames, dominios y perfiles. Combina múltiples APIs gratuitas con análisis asistido por IA para ofrecer resultados rápidos y contextualizados.

Diseñada para investigadores, periodistas, profesionales de ciberseguridad y cualquier persona interesada en conocer su propia huella digital — siempre respetando la legalidad y el consentimiento.

Construida con **FastAPI**, **SQLAlchemy** y un frontend ligero en HTML/CSS/JS, se despliega en segundos y funciona con cualquier proveedor de IA compatible con OpenAI (Groq, OpenAI, Ollama, OpenRouter).
